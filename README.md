# Mancala
ボードゲームをプログラミングで実現したいと思ったのと、対戦用AIを作ってみたいと思ったので。

現時点では、マンカラ・ベーシックという遊び方のみプレイできます。
また、AIは選択可能なマスのうちからランダムに一つを選択するだけです。
戦略なんてものはありません。

順次、遊び方の追加とAIの作成を行ってい予定です。
