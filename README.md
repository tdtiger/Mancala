# Mancala
ボードゲームをプログラミングで実現したいと思ったのと、対戦用AIを作ってみたいと思ったので。

現時点では、マンカラ・ベーシックとカラハという遊び方のみプレイできます。
AIとの対戦、もしくはスマホあるいはPC一台を二人で使うことにより対人戦もできます。

一応、AIは現在の手番のみを考慮して最善であると考えられる手を取ります。
次のターン以降の動きや、カラハにおける捕獲などは考慮していないので、まだまだ弱いです。

順次、遊び方の追加とAIの作成を行っていく予定です。

[遊び方参考サイト](https://recreation.or.jp/activities/genki_up/mancala/)(公益財団法人 日本レクリエーション協会)
