# Mancala
ボードゲームをプログラミングで実現したいと思ったのと、対戦用AIを作ってみたいと思ったので。

現時点では、マンカラ・ベーシックとカラハという遊び方のみプレイできます。
AIとの対戦、もしくはスマホあるいはPC一台を二人で使うことにより対人戦もできます。

ただし、AIは選択可能なマスのうちからランダムに一つを選択するだけです。
戦略なんてものはありません。

順次、遊び方の追加とAIの作成を行っていく予定です。
